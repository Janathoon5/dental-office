Automate Daily Reminders

To run reminders automatically every day, set up Windows Task Scheduler:

  1. Open Task Scheduler from the Start menu
  2. Click Create Basic Task
  3. Set trigger: Daily at your preferred time (e.g. 8 AM)
  4. Action: Start a program
  5. Program: {{ python_path }}
  6. Arguments: manage.py send_reminders
  7. Start in: {{ project_path }}
